Learning to Work With APIs

June 3rd, 2026

Working on LiftedInvoice has taught me SO much about UI and the Godot box containers. I feel like I could design all kinds of UI/UX systems, but connecting the code is always the hardest part!

I will be the first to admit that I have had to use AI a few times during this project to understand not only APIs but also SQLite. I had never worked with servers/databases before this either, so it has been quite a learning experience!

The specifics of the API I plan on using are the google calendar events: the user will be able to connect their google calendar and then within the app, when they create a workorder and put it on the schedule, it will also connect to their google calendars. So far I have the login section working and my google calendar is connected while I am testing, however I am struggling with my internal scheduling system.. especially because I want there to be as much customization for the user as possible!
